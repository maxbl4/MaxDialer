# MaxDialer — выбор фич (черновик)

Приложение для звонков в стиле Samsung «Телефон» (One UI 8.5) для любых Android-телефонов,
без зависимостей от библиотек Samsung. Работает как «Телефон по умолчанию»: набор номера,
журнал, контакты и собственный экран звонка.

**Рекомендация**
- ✅ — делать в первой версии
- 🟡 — позже
- ❌ — предлагаю не делать
- ⛔ — недоступно стороннему приложению

Ответьте номерами (например: «1–10 да, 12 нет, 15 позже»).
