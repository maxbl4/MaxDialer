# MaxDialer — выбор фич (черновик)

Приложение для звонков для Android. От DialerOne берём только функции: главный экран —
журнал вызовов и номеронабиратель вместе, умный T9-поиск по контактам, свайпы по журналу.
Визуальный стиль — Samsung One UI 8, без зависимостей от библиотек Samsung.

**Рекомендация**
- ✅ — делать в первой версии
- 🟡 — позже
- ❌ — предлагаю не делать
- ⛔ — недоступно стороннему приложению

Ответьте номерами (например: «1–10 да, 12 нет, 15 позже»).

### Ранжирование результатов поиска

Чем точнее совпадение, тем выше результат. Ориентировочный порядок:

1. Номер начинается с набранных цифр (5+ цифр — почти наверняка искали номер).
2. Имя (первое слово) начинается с набранного по T9.
3. Любое слово имени начинается с набранного по T9.
4. Совпадение по первым буквам слов (пункт 2).
5. Совпадение внутри слова имени.
6. Совпадение внутри номера.

Чем длиннее набранная строка, тем больше вес у совпадений по номеру. Внутри одного уровня
сначала идут недавние собеседники, потом частые, потом по алфавиту.
